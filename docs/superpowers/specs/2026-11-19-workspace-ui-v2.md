# 第二版阅读栏与工作区持久化

状态：用户已批准视觉方案，并要求会话历史与配置默认落在选定工作目录。本文件是实施规格，不是已上线行为。

## 视觉

落实 `screenshot_design_v2_main.png` 的阅读栏：灰白中性底，蓝色只用于主按钮和当前会话；轻侧栏；对话居中；少卡片、去掉紫色用户气泡；右侧检查器默认收起，由「检查」展开；输入框与目录/权限/模型状态分成两层。设置、批处理、弹窗和深色模式共用同一套 token。不删功能，不换框架。

## 存储

以界面或启动参数选定的工作目录为唯一数据根。解析相对路径时相对程序目录，不使用进程当前目录。

优先级：

1. 命令行 `--workspace`
2. 显式 `--config` 文件里的 `workspace.root`
3. 程序目录 `.workspace-root`（只有绝对路径，无密钥）
4. 程序目录旧 `config.json` 的 `workspace.root`
5. 用户主目录下的 `我的工作台`

配置正文：

1. 显式 `--config` 本轮就用这份文件，保存时同时写回该文件
2. 否则用 `<工作目录>/.agent/config.json`
3. 否则把程序目录旧 `config.json` 复制进工作区；原文件保留。目标已存在且内容不同则不覆盖，并写下说明

会话、批量、记忆、索引、快照、版本、模板、界面偏好都在该工作目录的 `.agent/`。机器密钥 `~/.local_agent_v2.key` 不属于某个工作区，不迁移。

切换工作目录 A/B 不复制会话和配置。目录不可写就报错退出，不把配置退回程序目录。
